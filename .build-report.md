```
{"message":"Your current plan does not support GitHub Pages for this repository.","status":"422"}
```

This repo is private; GitHub Pages on a private repo requires GitHub Team/Enterprise for an org (or the repo needs to be made public, which works on the free plan). Documented in the README's "Keyingi qadamlar" section. Once either (a) the repo is made public, or (b) the org's GitHub plan supports private Pages, enabling it is a one-time Settings → Pages → Source: `main` / `(root)` toggle (or retry the same `gh api` call).

DNS for `app.medpuls.uz` pointing at GitHub Pages is also not yet configured — that's a separate step on the domain's DNS provider (aHost, per `medpuls_crm/docs/infrastructure.md`), out of scope for this repo.
